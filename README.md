# Approval Inbox

**Client approvals without chaos.**

A lightweight client approval system for freelancers and agencies. Centralize approvals, revisions, and file feedback into one minimal workflow.

## Quick Start

```bash
# Prerequisites: Node.js 20+, pnpm 9+
pnpm install
pnpm dev
```

## Tech Stack

- **Frontend**: Next.js 15 (App Router) + TypeScript + Tailwind CSS + shadcn/ui
- **Backend**: Supabase (Postgres, Auth, Storage)
- **Real-time**: Server-Sent Events via Next.js API routes
- **Email**: Resend + React Email
- **Monorepo**: Turborepo + pnpm workspaces
- **Analytics**: PostHog
- **Deployment**: Vercel
